# Dino Dash

A small browser game built with plain HTML, CSS, and JavaScript.

## Play it locally

You can run the game in either of these ways:

- Open `index.html` directly in a browser, or
- Start a local server from this folder:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Controls

- `Space` or `↑` — Jump
- `↓` — Duck
- `X` — Fireball attack
- `Enter` — Start or restart the run

## Features

- Endless runner gameplay
- Pixel-style dinosaur art
- Obstacle dodging and fireball attacks
- Local best score saved in the browser
- Works without any external dependencies
